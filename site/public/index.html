Open-source archive engine · GPL-3.0

One engine. Seven archives with their own names.

Arkhiv is an open-source engine for print, audio and video archives. It keeps the original files, source metadata, review decisions and playback schedules. Each site built on it has its own name, design and domain.

Engine

What every archive gets

The same guarantees for print, audio and video.

OriginalsThe files, byte for byteA local copy is kept only after review, within a storage limit, with a verified hash of the original and a tested restore.
SourceWhere each item came fromSource metadata is kept apart from corrections, and corrections survive re-imports.
AccessWho approved it for displayNothing is public without an explicit approval record. Some sources stay streaming-only.
SearchTitles, credits and page textMetadata and page-text search, filters and calendar browsing for recordings by year or date.
PlaybackShared stationsScheduled channels where everyone hears the same thing. Each recording is verified before the schedule is extended.
RightsCredits stay with the itemOriginal rights and source credits remain with each item. Arkhiv asserts no license over them.
Releases

Each archive upgrades on its own schedule.

  1. Immutable release An engine release is pinned to a container digest, never a moving tag.
  2. Versions must match The API and every module version an archive uses must match before it can adopt a release.
  3. Additive migrations Database changes only add, and every past migration keeps its checksum.
  4. Reviewed per archive Each archive moves its pin in its own reviewed pull request. An engine update never replaces a brand’s interface.
